# 네이버 블로그

- 목적: 네이버 검색 유입. 네 채널 중 가장 길고, 유일하게 자세히 설명하는 채널이다.
- 원문을 그대로 복사하지 않는다. 같은 사실을 네이버 독자에게 맞게 다시 구성한다. 중복 문서로 보이지 않게 하려는 것이다.
- 제목: frontmatter 의 `title` 을 검색어가 들어간 제목으로 고친다(40자 안팎). 원문 제목을 그대로 두지 않는다.
- 태그: frontmatter 의 `tags` 에 검색어 중심 5~10개를 쓴다. `#` 과 쉼표 없이 한 단어씩(예: `tags: [AI업무자동화, 업무자동화, 프롬프트작성법]`). 너무 넓은 단어(AI, 일상)는 피한다.
- 구성:
  1. 도입 2~3문장. 고민이나 문제 상황으로 연다. 글 소개나 홍보로 시작하지 않는다.
  2. 소제목(`## `) 3~5개로 나눈 본문. 아주 쉽게, 짧은 문단으로 풀어 쓴다.
  3. 정리
  4. "원문에서 템플릿과 전체 과정을 볼 수 있어요." 한 줄
  5. 독자에게 말을 건네는 한 줄로 끝낸다.
- 길이: 1,500~3,000자. 글감이 짧은 경우는 아래 예외를 따른다.
- 링크 없는 작업(글감으로 만든 작업)이면 "원문에서 …" 안내 줄을 빼고, 글감 이야기로 마무리한다.
- 글감이 짧으면 길이를 채우려고 원문에 없는 사실을 더하지 않는다. 이때는 1,500자보다 짧아도 된다.
- 원문 링크는 붙여 넣기용 결과물을 만들 때 프로그램이 끝에 붙인다. 본문에 주소를 쓰지 않는다.
- 표와 코드 블록은 네이버 편집기에서 깨지기 쉽다. 목록이나 문장으로 풀어 쓴다.
